飞牛 OpenClaw 2026.10.5 兼容补丁包 v1.0.1

这是从本机已验证方案整理的社区兼容补丁，不是飞牛或 OpenClaw 官方插件。
保留飞牛管理平台，固定 OpenClaw 2026.10.5、微信插件 2.4.10。

适用范围
  fnOS x86_64，trim.openclaw 应用 0.1.5，单个 default 受管实例。
  只接受清单中记录的原始管理服务构建或本补丁的最终构建。
  未知构建、多实例、独立系统模式、新于 2026.10.5 的内核均拒绝自动修改。
  需要 root、Python 3.9+、tar、飞牛 Bun 依赖，以及 HTTPS 网络访问。
  必须在飞牛宿主机运行，不要在普通 Docker 容器内运行。

使用
  解压后先进入文件夹。可以核对文件清单：
    sha256sum -c SHA256SUMS

  只检查适用性，不修改任何文件、不重启服务：
    bash install.sh --dry-run

  安装、备份、升级并验证；默认下载专用 Chromium：
    bash install.sh

  不安装浏览器组件：
    bash install.sh --without-browser

  查看补丁、版本锁定及运行状态（只读）：
    bash check.sh

  回滚到某次安装前的完整快照：
    bash rollback.sh /vol1/@apphome/trim.openclaw/compat-backups/时间戳
  实际备份路径会在安装时打印，会根据应用所在卷自动解析。

安装过程
  1. 校验应用版本、服务源码 SHA-256 和默认受管实例。
  2. 正常停止网关和管理服务，完整备份 data、管理源码和命令包装器。
  3. 提供专用 Node.js 24.20.0；优先复用同版本本机二进制；缺失时从 Node.js 官方站点下载并核对 SHA-256。
  4. 应用逐行校验的兼容补丁，固定受管更新/重装目标为 2026.10.5。
  5. 用飞牛 Bun 安装精确版本，由官方 doctor --fix 迁移数据库/会话/配置。
  6. 已安装微信插件的情况下升级至 2.4.10；不自动接入新账号。
  7. 默认使用固定 Playwright 1.64.1 下载 Chromium revision 1248。
     配置无界面 openclaw 浏览器。保留 Chromium 沙箱，不自动关闭它。
  8. 关闭内核自动升级，启动服务，验证健康、网页脚本、iframe 和终端策略。
  9. 安装失败时尝试恢复完整备份；回滚前的数据会另行保留，不自动删除。

已解决的问题
  Node.js 版本不足；已删除的旧配置字段；微信旧插件 SDK 不兼容；
  已解压响应仍标记为 Brotli；飞牛同源 iframe 被禁止；设备签名令牌不一致；
  终端 WebAssembly 编译被 CSP 拦截；缺少受管 Chromium。

限制与维护
  安装期间服务会中断，完整备份会占用较多空间。脚本检查备份和回滚空间。
  新浏览器仍须按正常设备配对流程批准，本包不自动批准浏览器设备。
  飞牛应用包升级或重装可能覆盖这些本地补丁；覆盖后请先检查，不要强行套用。
  此包不锁定飞牛应用中心自身的版本，也不阻止管理员手动使用其他升级工具。
  浏览器仅代表能在 NAS 内启动和操作 Chromium，不会自动接管你电脑上的浏览器。
  当前环境的代理 Fake-IP DNS 会导致部分公网 URL 被内核策略拦截；本包不关闭
  SSRF 防护，也不改变宿主机 DNS。浏览器启动成功不等于所有网页都能访问。
  Chromium 所需系统库、CPU 或沙箱条件不满足时安装会失败并尝试回滚。
  内核升级会迁移 SQLite、会话和部分工作区文档，降级时必须完整恢复备份，
  不要只把 npm 包版本改回旧版。

数据范围
  压缩包仅含通用脚本、源码差异、版本哈希和说明，不含本机密钥、微信登录信息、
  聊天记录、服务环境变量、浏览器用户资料或数据库。
  运行后在 NAS 上生成的备份和日志可能含私密数据，保存在 root 专用备份目录，
  不应当拿来分享。补丁包中不分发飞牛完整服务源码或浏览器/Node.js 二进制。

验证情况
  本机：网关启动/停止/重启、健康检查、微信渠道加载、历史会话读取；
  Chromium 实测飞牛同源 iframe 页面、设备认证、终端 Bash 提示符与 WASM；
  受管 Chromium 启动、创建标签页、截图。
  打包脚本：源码补丁结果哈希、dry-run、只读检查、异常回滚单元测试。
  已在本机新装的原版 2026.5.4 上完成升级到 2026.10.5、健康和浏览器启动验证；仍未在另一台独立 NAS 上实测。

文件
  compat.py             安装/检查/回滚实现（Python 标准库）
  install.sh            安装入口
  check.sh              只读检查入口
  rollback.sh           显式回滚入口
  manifest.json         固定版本和源码 SHA-256
  payload/monitor.patch 通用管理平台补丁
  tests.py              安装保护逻辑测试
  SHA256SUMS            包内文件校验值
